# Customer Data Analysis and Visualization Dashboard
### Project Overview
This project explores a customer dataset containing 15 columns with different data types. Using Microsoft Excel, I examined the dataset through column filters, sorted annual income in descending order, and performed basic calculations to summarize key customer information.

To make the data easier to interpret, I created a dashboard featuring key customer metrics, a gender distribution doughnut chart, a bar chart showing customer distribution by city, and a line chart illustrating purchase history over time.

The dashboard provides a visual overview of customer demographics, income, subscription status, and purchasing activity, making the information easier to review and compare.

### Tools and Techniques
- Microsoft Excel
- Data filtering and sorting
- Basic calculations and summary metrics
- Doughnut chart, bar chart, and line chart
- Dashboard design and data visualization

### Project Goal
To explore customer data and present selected metrics and patterns in a clear, accessible dashboard.

### Deliverables
- Excel workbook containing the dashboard
- Dashboard screenshots
- Project report in PDF format
